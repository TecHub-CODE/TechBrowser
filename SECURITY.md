# Security Policy

## Supported version

Security fixes target the current Windows 10/11 release. The Windows 8.1 legacy build
uses an end-of-life browser runtime and is not security-supported.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Contact TechHub Studio
through the support channel listed at https://techbrowser.site and include:

- the affected version;
- steps to reproduce;
- the expected security impact; and
- any suggested mitigation.

Do not include passwords, access tokens, private user data or active API keys.
